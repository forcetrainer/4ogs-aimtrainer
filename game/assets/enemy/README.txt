Enemy figure and animations: Mixamo (Adobe), free to use in games with an
Adobe account; the files themselves may not be redistributed, so they are not
in version control.

Downloaded 2026-11-12: "Basic Shooter Pack" (the X Bot mannequin plus rifle
animations) and "Dying". Files are renamed to lower case with underscores.

Used by game/scripts/enemy_model.gd, which lists the file each animation
comes from. To add a stance, download the animation for any Mixamo character
(FBX, 30 frames per second, no keyframe reduction) and save it here as:
  (crouch, walk, run and death animations are installed from the Pro Rifle Pack)
  stand_to_prone.fbx    going from standing to lying (the drop shot)
To change the figure, download any Mixamo character "With Skin" and save it
as character.fbx.
